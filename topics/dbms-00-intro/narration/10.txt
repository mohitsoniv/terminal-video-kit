 ||| दूसरा हिस्सा है DML, यानी Data Manipulation Language। यह ढाँचे के अंदर data को संभालती है। INSERT, UPDATE, DELETE और SELECT इसी में आती हैं। ||| DML = INSERT, UPDATE, DELETE, SELECT
INSERT INTO products ||| यह रही DML। हम products table में एक row डाल रहे हैं।
^INSERT 0 1 ||| INSERT 0 1 का मतलब है एक row अंदर चली गई।
SELECT \* FROM products ||| और SELECT से वही data वापस पढ़ा जा सकता है।
^ +1 \| Laptop ||| यह रही हमारी row। id एक, और name Laptop।
 ||| तो सीधा फ़र्क़ यह है। DDL डिब्बा बनाती है, DML उस डिब्बे में सामान रखती और निकालती है।
